# VScode 与 Linux 入门

讲师：计32 刘昕雨

## 课程简介

本讲从操作系统的基础概念出发，介绍课程作业和项目开发中常用的 Linux 环境与 VS Code 工具。我们将简要讲解操作系统如何管理进程、内存和文件，认识内核、终端与 Shell 的关系，并梳理 Windows、macOS 与 Ubuntu 的特点，帮助大家理解日常开发工具背后的运行环境。

课程将结合实际操作，演示如何通过 WSL 在 Windows 上使用 Linux，讲解文件管理、权限、管道与重定向等常用命令，以及通过 SSH 连接远程服务器的方法。在此基础上，介绍 VS Code 的基本使用与远程开发流程，包括 WSL、Remote-SSH 扩展，并以一个简单的 C/C++ 项目演示编译工具链、CMake 和代码调试的基本用法。希望帮助大家理解“代码如何在操作系统中运行”，掌握本地与远程开发的基本流程，为后续课程学习、项目实践和科研打下基础。

# 前端基础

讲师：计金3 刘宇轩

## 课程简介

本课程面向希望了解 Web 开发的同学，从软件工程中的前端角色出发，介绍前后端的职责分工，以及浏览器与服务器如何协作。结合网页访问、即时聊天和流式回复等场景，讲解 HTTP/HTTPS 的基本原理，比较普通请求、WebSocket 与 SSE 的交互方式。随后介绍 HTML、CSS、JavaScript 的分工，以及浏览器如何将代码转化为可见、可交互的页面。课程以概念讲解和简单示例为主，帮助大家理解从用户操作、数据交互到页面更新的完整过程，为后续开发实践打下基础。

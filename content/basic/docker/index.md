# Docker 入门

讲师：计25 于新雨

## 课程简介

如果你厌倦了配环境时候的各种依赖问题，不妨试试 Docker，它把应用和依赖打包成可复制的镜像，一次配好、各处运行，同时 Docker 内的环境和主机隔离，保证了安全性。同时它不只是配环境工具，更是 AI 时代的基础设施底座。LLM 推理、ComfyUI、向量数据库、Agent 沙箱、论文复现，背后常常都是容器。2026 年 WSL 3 正式内置 Linux 容器能力，Windows 用户不装 Docker Desktop 也能用 wslc 跑 OCI/Docker 镜像，并支持 GPU 直通跑 CUDA 容器。本次科协培训不只讲 Docker 具体怎么用，更讲更高层次的 Docker 在个人开发中什么时候用、在 AI 工作流里处于什么位置。让我们一起进入容器的“小”世界，不仅方便个人的 coding 探索，更深入了解现代软件的部署底座。
